# Tic Tac Toe

A polished, accessible Tic Tac Toe game for the browser.

## Run locally

- Start a local server in this folder:
  ```bash
  python3 -m http.server 8080
  ```
- Open `http://localhost:8080` in your browser.

## Features
- Two modes: Vs Computer (unbeatable) or Two Players
- Choose to play as X or O
- Keyboard accessible: Tab to a cell, Enter/Space to mark
- Winning line highlight, responsive design
